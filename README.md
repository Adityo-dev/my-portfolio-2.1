# Aditto Dev - Full Stack Developer Portfolio

A premium, minimal, and editorial-style developer portfolio built with Next.js, Tailwind CSS, and Framer Motion. The design focuses on a dark luxury aesthetic, strong typography, and a "Developer as a Digital Product Builder" narrative.

## 🚀 Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (App Router)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **UI Components:** [shadcn/ui](https://ui.shadcn.com/)

## ✨ Key Features

- **Editorial Design Language:** High-end, structured layouts with 1px borders, subtle gradients, and sophisticated typography.
- **Dynamic Interactions:** Smooth page transitions, hover effects, and scroll-triggered animations powered by Framer Motion.
- **Component Architecture:** Scalable section-based components following Next.js App Router best practices.
- **Fully Responsive:** Carefully crafted layouts that hold up from 320px phones to 1440px desktop screens.

## 🛠️ Getting Started

First, clone the repository and install the dependencies:

```bash
# Install dependencies (using pnpm, npm, or yarn)
pnpm install
```

Then, run the development server:

```bash
pnpm dev
# or
npm run dev
# or
yarn dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## 📂 Project Structure

- `src/app/(main)/(home)/`: Contains the main homepage and its section-based components.
- `src/components/`: Contains shared global components like `Navbar`, `Footer`, and `CTA`.
- `src/components/ui/`: Contains reusable generic UI components (shadcn/ui).
